# Baneshwari Tour & Travels

Vercel-ready source code for the Baneshwari Tour & Travels website.

## Local setup

1. Install [Bun](https://bun.sh/).
2. Run `bun install`.
3. Run `bun run dev`.
4. Open `http://localhost:8080`.

## Deploy to Vercel

1. Upload this folder to a Git repository.
2. Import that repository into Vercel.
3. Use **Other** as the framework preset if it is not detected automatically.
4. Set the build command to `bun run build`.
5. Leave the output directory empty; Nitro writes Vercel's deployment output automatically.

No environment variables are required for the current website.
